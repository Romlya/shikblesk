# ShikBlesk — Лендинг косметолога-эстетиста

Одностраничный сайт для кабинета косметолога-эстетиста **Евгении** в Мытищах (Московская область).

**Живой сайт:** https://shikblesk.vercel.app  
**Репозиторий:** https://github.com/Romlya/shikblesk

---

## Что сделано

- Современный креативный лендинг в стиле «нарисовано карандашом»
- Полный список услуг с ценами, разбитый по категориям (Чистки, Аппаратные, Пилинги, Уходы, Другое)
- Модальные окна «Подробнее» с описанием процедуры и ожидаемыми результатами
- Форма онлайн-записи
- Адаптивная вёрстка (мобильные + десктоп)
- Контакты: телефон, адрес, часы работы + блоки под Telegram и Max
- Деплой на Vercel с привязкой к GitHub

## Дизайн-система

### Стиль
- Эстетика «карандашного наброска» / hand-drawn
- Бумажная текстура фона
- Неровные «живые» границы кнопок и карточек
- Минималистичная иллюстрация портрета (SVG)

### Цвета (CSS-переменные)

| Переменная       | Значение              | Назначение                  |
|------------------|-----------------------|-----------------------------|
| `--ink`          | `#2c2c2c`             | Основной текст, линии       |
| `--ink-light`    | `#4a4a4a`             | Вторичный текст             |
| `--paper`        | `#f7f3eb`             | Фон страницы                |
| `--paper-dark`   | `#ebe4d6`             | Фон секций (запись)         |
| `--accent`       | `#c45c4a`             | Акцент (кнопки, цены, губы) |
| `--accent-soft`  | `#e8a598`             | Мягкий акцент               |
| `--line`         | `#3d3d3d`             | Обводки                     |
| `--shadow`       | `rgba(44,44,44,0.12)` | Тени                        |

### Шрифты

- **Заголовки / логотип / рукописный стиль:** [Caveat](https://fonts.google.com/specimen/Caveat) (Google Fonts)
- **Основной текст:** [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)

Подключение:
```html
<link href="https://fonts.googleapis.com/css2?family=Caveat:wght@400;500;600;700&family=Inter:wght@300;400;500;600&display=swap" rel="stylesheet">
```

### Ключевые CSS-особенности
- Неровные `border-radius` для «нарисованного» эффекта
- `filter: drop-shadow` на иллюстрации
- Плавные переходы и hover-эффекты с небольшим сдвигом
- Бумажный noise-текстура через SVG filter на `body::before`
- Волнистые разделители секций (SVG)

## Основные секции сайта

1. **Header** — логотип + навигация + кнопка «Записаться»
2. **Hero** — заголовок, описание, кнопки, иллюстрация, цифры
3. **О нас** — краткая информация о мастере
4. **Услуги** — вкладки категорий + карточки услуг с ценами и кнопками «Подробнее» / «Записаться»
5. **Запись** — форма + контакты (телефон, адрес, время, Telegram, Max)
6. **Отзывы**
7. **Footer**

---

## JavaScript-функционал

- Переключение категорий услуг (табы)
- Модальные окна с описанием процедур (`servicesData` объект)
- Мобильное меню
- Плавный скролл
- Тост после отправки формы
- Минимальная дата в календаре формы

Данные услуг и описания хранятся в объекте `servicesData` внутри `<script>`.

## Примечания для других ИИ / разработчиков

- Весь код находится в одном файле `index.html`.
- Стили — внутри `<style>`, скрипты — внутри `<script>`.
- Цвета и отступы лучше менять через CSS-переменные в начале `<style>`.
- Иллюстрация в hero — это SVG внутри `.sketch-frame`. Чтобы заменить — просто подставь новый SVG.
- Модальные окна услуг управляются объектом `servicesData` и функциями `openModal` / `closeModal`.
- Форма записи пока только показывает тост (бэкенда нет). При необходимости можно подключить Formspree, Telegram Bot API или другой сервис.
